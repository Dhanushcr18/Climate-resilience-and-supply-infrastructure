1.0 EQUATION SPEC

Dynamic Corridor Risk Formulation

EQUATION ID: RES-EQ-7701

The composite risk score R(c, t) evaluates route viability across critical mountain ghats during monsoonal events. It computes an instantaneous slip/inundation hazard index between 0.00 and 1.00:

R =
0.45 × Ssat Soil Saturation
+
0.20 × Prain Rain Intensity
+
0.25 × Θslope Terrain Incline
+
0.10 × Vdrain Drainage Deficit
S_sat (Soil Saturation) WEIGHT: 45%

Measures volumetric water content vs pore collapse limit derived from Topsoil Moisture Depth (0-40cm).

Critical Threshold: > 85% Volumetric Saturation
P_rain (Rainfall Intensity) WEIGHT: 20%

Sustained precipitation flux over a rolling 3-hour moving window normalized against 10-year historical monsoon peaks.

Critical Threshold: > 65 mm/hr Continuous Surge
Theta_slope (Terrain Incline) WEIGHT: 25%

Tangential gradient along the road corridor extracted from SRTM 30m digital topography data.

Shiradi / Charmadi Ghat: Slope ≥ 32.4° Shearing Limit
V_drain (Drainage Vulnerability) WEIGHT: 10%

Culvert blockage coefficients, roadside culvert siltation indexes, and structural masonry age factors.

Culvert Blockage: > 70% Flow Cross-section Impeded

export function computeCompositeRisk({ soilSat, rainIntensity, slopeDeg, drainageBlock }) {
  // Normalized to [0.0, 1.0] range
  const s = Math.min(1.0, Math.max(0.0, soilSat / 100));
  const r = Math.min(1.0, Math.max(0.0, rainIntensity / 100));
  const g = Math.min(1.0, Math.max(0.0, slopeDeg / 45.0)); // 45 deg max shear
  const d = Math.min(1.0, Math.max(0.0, drainageBlock / 100));

  // Scientific Weights: Hydro Saturation (0.45), Rain (0.20), Gradient (0.25), Culvert (0.10)
  const score = (0.45 * s) + (0.20 * r) + (0.25 * g) + (0.10 * d);
  return Number(score.toFixed(4));
}
